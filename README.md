# 🍔 Aplikasi Kasir Makanan (Point of Sale)

Aplikasi kasir makanan berbasis web yang dirancang untuk memudahkan pencatatan pesanan, pengelolaan menu makanan/minuman, serta kalkulasi pembayaran transaksi secara praktis dan responsif.

---

## 🚀 Fitur Utama
* **Daftar Menu Makanan & Minuman:** Menampilkan katalog produk beserta harga dan kategori.
* **Keranjang Pesanan (Cart):** Menambahkan item pesanan dan menghitung total harga secara otomatis.
* **Sistem Pembayaran:** Input nominal uang pembeli dan kalkulasi kembalian.
* **Cetak Struk:** Generasi bukti pembayaran transaksi.

---

## 🛠️ Teknologi yang Digunakan
* **HTML5 / CSS3 / JavaScript (ES6)**
* **Git & GitHub** (Version Control)
